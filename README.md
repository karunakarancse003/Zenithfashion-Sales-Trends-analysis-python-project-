# Zenithfashion-Sales-Trends-analysis-python-project-
ZenithFashion – Sales &amp; Loss Analysis (FY2023–2024) using Python. Analyzed 485 orders, ₹38.73 Lakhs revenue and ₹9.01 Lakhs profit. Performed Data Cleaning, EDA and Return Rate Analysis using Pandas and Matplotlib to identify business gaps and actionable insights.
